웹 에디터 서비스

상품명을 입력하면 AI가 상품상세페이지를 자동 생성하는 웹 에디터입니다.
AI가 생성한 콘텐츠를 사용자가 쉽게 수정할 수 있도록 편집 기능과 사용자 경험(UX) 개선에 집중했습니다.

개발 이슈

이슈
글로벌 미들웨어에서 모든 요청마다 회원/서비스 검증 API를 호출하면서 불필요한 요청이 누적되어 API 응답 속도 저하
해결
요청별로 필요한 검증 로직만 실행하도록 글로벌 미들웨어 구조를 분리하여 불필요한 API 호출을 제거했습니다. 이를 통해 API 처리 속도를 약 40% 향상시켰습니다.
이슈
에디터에서 생성한 이미지의 품질과 관련된 고객 문의가 지속적으로 발생
해결
Python 기반 이미지 추출 서버를 구축하고 Playwright를 활용해 브라우저 렌더링 결과를 이미지로 추출하는 방식으로 개선했습니다. 이를 통해 이미지 품질을 안정화하고 관련 고객 문의를 약 66% 감소시켰습니다.
이슈
편집 중 페이지 이탈이나 예기치 않은 종료로 작성 데이터가 유실되는 고객 문의가 발생
해결
편집 데이터를 주기적으로 저장하는 자동저장 기능을 구현해 작업 복구가 가능하도록 개선했습니다. 이를 통해 데이터 유실 관련 고객 문의를 약 90% 감소시켰습니다.

개발 후 느낀점

고객 문의를 통해 실제 사용 과정에서 반복되는 불편을 확인하고 이슈를 유형별로 정리한 뒤 발생 빈도와 사용자 영향도를 기준으로 개선 우선순위를 정하는 방식을 경험했습니다. 자동저장처럼 사용자 불편을 줄일 수 있는 기능을 먼저 제안 및 개선하는 관점으로 개발하게 되었습니다.

브라우저와 OS 환경에 따라 폰트 렌더링 방식과 설치된 시스템 폰트, fallback 폰트가 달라지면서 폰트, 줄바꿈, 레이아웃 등이 달라져 에디터에서 보이는 콘텐츠와 추출된 이미지 결과가 일치하지 않을 수 있다는 점을 경험했습니다. 프론트엔드 구현뿐 아니라 브라우저, OS, 시스템 폰트 등 실행 환경까지 함께 확인하며 원인을 분석하게 되었습니다.

폴더 관리 기능을 설계할 때 현재 요구사항만 충족하기보다 폴더-콘텐츠의 계층 구조, 이후 하위 폴더 확장까지 고려해 DB 스키마와 API 구조를 설계했습니다.

신규 기능이나 공통 로직을 변경할 때는 기존 기능에 미치는 영향을 먼저 확인하는 과정이 중요하다는 점을 배웠습니다. 테스트 체크리스트를 작성하고 개발/스테이징 환경에서 주요 시나리오를 검증한 뒤 배포하는 방식을 적용했습니다. 이를 통해 실서비스에서 발생할 수 있는 오류를 줄였습니다.

기술 구성

시스템 구성도

  • Laravel 기반 API 서버로 구성된 웹 에디터 서비스의 개발 및 운영을 담당했습니다.
  • Service API가 이미지 처리 및 비즈니스 로직을 담당하도록 구현했습니다.
  • Python 기반 Capture API와 Image Thumbnail API를 구축해 이미지 캡처, 썸네일 생성 등 전처리 기능을 제공했습니다.
  • 네이버 CLOVA API 연동하여 상세페이지 문구 자동 생성 기능을 개발했습니다.
  • 관리자 사이트는 Laravel 기반으로 콘텐츠, 고객, 서비스 관리 기능을 개발했습니다.
