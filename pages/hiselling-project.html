쇼핑몰통합관리 서비스

여러 온라인 쇼핑몰의 상품, 주문, 배송 등 운영 업무를 통합 관리할 수 있는 솔루션입니다.
반복 업무를 자동화하고 관리 포인트를 일원화하여 업무 생산성을 높이고 운영 비용을 절감할 수 있습니다.

시스템 구성도

  • UI Service(React)와 Backend/Core Service(Node.js)로 구성된 쇼핑몰 통합관리 서비스입니다.
  • 사용자는 UI Service를 통해 상품, 주문, 배송 관리 기능을 이용하며, UI Bridge가 Backend Service와 연동하여 비즈니스 기능을 제공합니다.
  • Backend Service는 도메인별 API로 구성해 기능별 책임을 분리하고 Kafka 메시지 큐로 Backend Service 작업을 비동기로 처리합니다.
  • Next.js 기반 Admin Service에서 마켓 기초 데이터 등 운영 기능을 관리할 수 있도록 구현했습니다.
  • Docker/Kubernetes 컨테이너 환경에서 서비스를 운영했습니다.
